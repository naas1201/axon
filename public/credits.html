Things this site does not use

No analytics, no tracking pixels, no external fonts, no JavaScript CDN, no cookie banner. The page loads one stylesheet and one small script from its own origin. There is nothing to consent to.

Type

Set in the system serif and system sans stacks, with monospace for code. No webfont is downloaded, which keeps the page fast and the typography honest on every platform.
