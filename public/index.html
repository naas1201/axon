POST JavaScript, get JSON back. axon runs untrusted code in a fresh WebAssembly sandbox: no filesystem, no network, no state between calls. Math, dates, regex and npm packages, without spending model tokens on the arithmetic.

One request, one answer

curl 
curl -s https://axon.va-n.com/api/v1/execute \
  -H 'content-type: application/json' \
  -d '{"code":"return 2 + 2"}'
{"ok":true,"result":4,"logs":[],"meta":{"wall_ms":1.8,"modules":[],"engine":"quickjs 2025-09-13"}}

The sandbox is stateless by construction. Every call gets a new QuickJS runtime, a new heap and a deadline. Nothing you send is retained, and nothing you send can reach the network.

What it will never do

Security model
01

Keep state

A new runtime and a new heap per request. No globals survive, no module registry is reused, no cache is visible from inside. Two calls cannot talk to each other.

02

Reach the network

There is no fetch, no sockets, no XMLHttpRequest inside the sandbox. Packages are fetched by the Worker before evaluation starts, from esm.sh only.

03

Touch a disk

No filesystem, no process, no require, no environment. Node builtins such as node:fs are refused before a byte is evaluated.

The measured envelope

Free plan · 2026-10-19
Scenario Measured Why
Arithmetic, strings, regex, dates 2 to 6 ms CPU One parse, one evaluation, no I/O.
Full lodash import (warm) 90 to 170 ms CPU 82 KB bundle parsed by QuickJS. Submodule imports cost far less.
Median wall time, trivial call about 5 ms Server side, measured with wrangler tail.
95th percentile wall, trivial call about 50 ms Cold isolate, GC, or a first request in a new colo.
Runaway loop cut off about 250 ms CPU A fixed instruction budget, not a wall clock.
Heap ceiling per call 32 MB max Requested per call, 16 MB default.

Cloudflare publishes 10 ms of CPU per request on the free plan. Measured on this deployment, a trivial call uses 2 to 6 ms and a full lodash import uses 90 to 170 ms, and the platform served both. Do not plan against the higher numbers: keep calls small, prefer a submodule import over a whole library, and read the FAQ before pointing a loop at it.

Where it earns its place

Use cases
  • Tool calls for agents. Replace "the model does arithmetic" with a deterministic interpreter.
  • Data shaping. Group, sort, sum and rename JSON before it goes back into a prompt.
  • Validation. Regex, schemas and date rules that must be exact, not plausible.
  • Dates and time zones. Business days, deadlines, offsets, ISO formatting.
  • Unit and currency math. Rounded once, at the end, in one place.
  • Package calls. lodash, date-fns, zod and anything else esm.sh can bundle.
